Experimental data
=================

Apply the reconstruction workflow to measured data. The dendrite notebook
explains normalisation, geometry conventions and settings adapted from the
standalone demo. It requires a working ToMoBAR CUDA environment and the bundled
I12 archive, with a download fallback when running outside a checkout.
